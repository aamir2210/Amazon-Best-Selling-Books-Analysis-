## 📖 Overview
This interactive web app analyzes **Amazon Best-Selling Books (2009–2019)** and provides insights into:
- 📊 Pricing trends  
- ⭐ Rating distributions  
- ✍️ Top authors and genres  
- 📥 Downloadable filtered data  

Built with **Streamlit, Pandas, and Altair**, it lets users explore books dynamically with filters and visualizations.

---

## ✨ Features
- **Interactive filters**: genre, year range, reviews, rating, and price  
- **KPIs**: total books, unique authors, average rating, median price  
- **Charts**:  
  - Top 10 authors by number of bestsellers  
  - User rating distribution  
  - Price vs. Rating scatter plot  
- **Download option**: export filtered dataset as CSV
